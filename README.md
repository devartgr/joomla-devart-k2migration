# joomla-devart-k2migration
K2 to Joomla 6 migration tool. Move a legacy Joomla 3 K2 site to native Joomla 6 articles: items, categories, tags, users, menus and images. Resumable in the browser, incremental sync while the old site stays live, preserved IDs, rollback. Proven on 230,000 articles and 90GB of media.
